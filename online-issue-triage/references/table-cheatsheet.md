# 排查数据关系速查

本文件提供关系类型，不维护组织内部库表清单。实际实例、库、表、字段和状态值必须从项目代码、Mapper、元数据及当前环境确认。

| 要回答的问题 | 需要定位的关系 |
|---|---|
| 对象是否进入任务 | 任务主记录、任务明细、导入批次与去重/拦截结果 |
| 对象为何停止流转 | 流程实例、节点运行记录、当前节点、关联请求与锁/重试状态 |
| 通知是否发出 | 发送主记录、发送明细、模板、外部渠道返回与回调 |
| 数据是否属于当前范围 | 租户、用户、任务、创建时间和授权上下文 |

例如可以用虚构的 `example_db.demo_task`、`demo_task_detail`、`demo_flow_run` 表示这些关系，但这些名称不代表实际系统中的可查询对象。

## 使用原则

- 先确认环境、实例和数据库，再发现目标表。
- 用主外键和实际 SQL 证明关联，不根据字段名称相似猜连接关系。
- 状态值、枚举、号码加密方式和租户边界以现行实现为准。
- 行数据查询遵守对应数据库技能的范围确认要求；权限不足时报告缺口，不切换历史库、镜像或其他租户。
